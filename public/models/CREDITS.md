# Credits — the hero room and the house

Every 3D object in the hero room is built in code (`src/three/Room.tsx`, with the macropad
from `src/three/Macropad.tsx` and Tala's notebook from `src/three/TalaDesk.tsx`). The house
under it (`src/three/HouseModel.tsx`) is built in code too, except its furniture: the 25
pieces in `furniture/` are from Kenney's Furniture Kit (CC0), repainted in the site's palette
by `src/three/furniture.tsx`.
